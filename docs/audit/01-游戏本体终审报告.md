## 三、逐项功能验证（任务指定的 7 项）

### 3.1 四轮审案

- `src/data/story.js` 含四堂完整节点：第一堂 `鸣冤·初审`、第二堂 `验刀·追凶`（`investigation` / `linking`）、第三堂 `对质·辨伪`（`successFlags`）、第四堂 `御压·终审`（`c4_final`）。
- `src/pages/GamePage.jsx` 由 `game.courtIndex`、`game.nodeId`、`game.phase` 派生当前 `court` / `node` / `speaker`，状态机集中在 `src/App.jsx`（`freshGame`、`handleAdvance`、`handleChoice`、`handleUndo`、`handleLink`、`continueGame`）。
- 真实走通：`npm run test:e2e` 跑通首页 → 片头 → 第一堂质询 → 手动存档 → 刷新续档 → 第二堂关联 → 第三堂证据质询 → 第四堂皇权压力 → 终审二次确认 → 结局（`27 checks`）。
- 章节页：`npm run test:chapter-font` `55 checks`；`check:no-bold` 确认大标题 `font-weight: 400` + `font-synthesis: none`。

**结论：通过。** 四堂结构完整、可推进、可回退、二次确认在位。

### 3.2 证物关联

- `src/data/evidence.js`：8 件证物静态档案；3 条 `evidenceLinks`（`kinship` / `command` / `loyalty`）；`CORE_EVIDENCE_IDS` 为 7 件关键证物（状纸属程序文书，不计入事实证明）。
- `src/components/EvidenceLinkBoard.jsx`：最多选 3 件、按排序后 id 匹配 `evidenceLinks`、重复关联被拦截、成功才调用 `onLink(result)` 写入 flag。
- `GamePage.jsx`：`c2_form_links` 要求 `linkCount >= 3`，否则打开关联台；`proofMissing(choice)` 禁用缺证选项。

**结论：通过。** 关联规则、去重、缺证门禁均在数据层与 UI 双层约束。

### 3.3 人物质询

- 第三堂 `successFlags` 驱动印证结果。
- `src/game/endings.js` 的 `REQUIRED_PROOF_FLAGS` 冻结 6 个 flag：`kinship_linked`、`command_linked`、`loyalty_linked`、`identity_confirmed`、`command_confirmed`、`hanqi_truth_confirmed`。
- `hasVerifiedInquiry(state)` 要求 6 个 flag 全部命中，缺一即落入 `pending`。

**结论：通过。** 质询结果真实进入结局判定链，不是装饰性交互。

### 3.4 四种结局

- `endingCatalog` 四条：`justice` 正法昭彰、`defiance` 抗旨开铡、`power` 权门蔽日、`pending` 悬案待雪。
- `evaluateEnding(state)` 判定顺序：`yield → power`、`defer → pending`、证物链或质询不全 → `pending`、`law → justice`、`defy → defiance`、未知值 → `pending`（不擅作宣判）。
- `src/game/endings.test.js` 9 个单元测试覆盖四结局判定、缺证 / 缺 flag、重复证物、结局文案完整性。
- `npm run test:endings`：四个结局页面均可达（`4 个结局`）。

**⚠️ 但存在测试缺口（详见第五章 P2-1）**：`scripts/e2e-endings.mjs` 是通过 `localStorage.setItem('kaizha:auto', ...)` **注入终局 state** 验证结局页可达，并非从四堂审案真实自然走到四种结局。本次审查如实指出，不把「页面可达」等同于「全流程触发已验证」。

**结论：判定逻辑与页面渲染通过；全流程自然触发覆盖不足，列为 P2。**

### 3.5 自动存档与刷新恢复

- `src/game/save.js`：`SAVE_VERSION = 1`；`STORAGE_KEYS = { auto, manual, endings }`。
- `parseEnvelope()` 校验 JSON 可解析、对象类型、`version` 一致、`state` 有效、结局档案为数组；损坏 / 版本不符 / 缺档均返回可读原因而非抛异常。
- `saveGame()` / `loadGame()` / `clearSave()` / `recordEnding()`（按 `endingId` 去重）/ `autoSave()` / `manualSave()`。
- 只读探针实测：刷新前后 `courtIndex=0`、`nodeId=c1_plaint`、`phase=response`、`evidence=["complaint"]`、`historyLen=1` **完全一致**，`same=true`。

**结论：通过。** 自动存档、损坏检测、刷新恢复均有真实运行证据。

- `check:fonts`：档案标题族 `FZSongKeBenXiuKai, "LXGW ZhenKai", ZhuqueFangSong, serif`，`30px`。
- 字体授权：`public/assets/fonts/` 内含 `OFL-LongCang.txt`、`OFL-ZhiMangXing.txt`、`字体接入说明.txt`；方正两款仅以 `local()` 声明，未授权商业字体文件**未随包分发**。

### 3.7 手机端适配

## 十、最终运行与构建说明（交付格式 H）

```bash
npm install          # 安装依赖
npm run dev          # 本地开发预览 http://127.0.0.1:5173
npm run build        # 产出离线可用的 dist/
npm run preview      # 预览生产构建
```

- **离线性**：游戏不依赖外部服务器、在线 API 或在线图片素材；字体、片头视频、立绘、背景全部随包分发。
- **片头**：`public/assets/video/intro.mp4`，H.264 (avc1) + AAC-LC + yuv420p，1280×720，74 秒，约 24.43 MB，`+faststart` 无损重封装；`test:e2e` 含「片头画面已解码（非黑屏）」断言（`videoWidth > 0 && videoHeight > 0`）。
- **构建实测**：`index.html 0.60 kB`、`assets/index-*.css 56.88 kB`、`assets/index-*.js 212.87 kB`，`built in 783ms`。
- **资源体积**：`dist` 约 67.8 MB；`public/assets` 中 `video 24.43 MB / 1`、`fonts 19.08 MB / 7`、`characters 15.38 MB / 27`、`source 4.18 MB / 16`、`backgrounds 1.6 MB / 3`、`logo 1.23 MB / 1`、`portraits 1.22 MB / 5`。
- **`.gitignore`**：覆盖 `node_modules`、`dist`、`dist-ssr`、`*.local`、`.DS_Store`、`.vite`、`release`、`test-artifacts`；未发现 `.env`、密钥、`.pem`、credentials、`.log` 等敏感文件。
- **桌面版**：`electron/main.cjs`、`electron/preload.cjs` 与打包配置已就绪；需先 `npm install --save-dev electron electron-builder`，再 `npm run desktop:dist` 产出 `release/开铡-Setup-1.0.0.exe`。
- **全量回归**：按第四章表格 14 条命令逐条执行，均以 `EXIT=0` 为准；`test:e2e` / `test:stage` 等依赖系统 Edge（`C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe`），换机需改 `executablePath` 或执行 `npx playwright install chromium`。
