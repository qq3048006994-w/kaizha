## 阶段 1 · 安装 Git（本机当前没有）

### 方式 A：命令行（推荐，后面步骤要用）

1. 打开 <https://git-scm.com/download/win>，下载 **64-bit Git for Windows**。
2. 双击安装，一路 `Next` 用默认选项即可；到 **Adjusting your PATH environment** 那页保持默认的 `Git from the command line and also from 3rd-party software`。
3. 装完 **关掉并重开** PowerShell / 终端（不重开找不到 git）。
4. 验证：


   ```powershell
   git --version
   ```
   显示 `git version 2.x.x` 即成功。

### 方式 B：完全不想敲命令 → GitHub Desktop

打开 <https://desktop.github.com/> 下载安装、登录 GitHub 账号。它自带 Git，会自动处理登录和推送。若选 B，阶段 2 / 3 直接看每阶段末尾的「图形界面替代」小节。

## 阶段 3 · 在 GitHub 建空仓库并推送

**第 1 步 · 建空仓库**

打开 <https://github.com/new>：

- Repository name：`kaizha-game`
- Public / Private 都行（Private 也可以，只要阶段 4 授权时选中它）
- **三个初始化选项一个都不要勾**：`Add a README file`、`Add .gitignore`、`Choose a license` 全部留空 → 必须是**空仓库**，否则和本地冲突
- 点 **Create repository**

**第 2 步 · 复制页面给出的地址**，形如 `https://github.com/<你的账号>/kaizha-game.git`

**第 3 步 · 回到 PowerShell 执行**（地址换成你自己的）

```powershell
git remote add origin https://github.com/<你的账号>/kaizha-game.git
git push -u origin main
```

> 🔑 **最容易卡住的一步：认证**。GitHub 早已不支持「账号 + 密码」推送。
>
> - 首选：第一次 push 会弹出登录窗口 → 选 **Sign in with your browser**，用浏览器授权即可（Git Credential Manager 自动处理）。
> - 若没弹窗 / 报 `Authentication failed`：
>   - 最省事 → 改用 GitHub Desktop 的 **Publish repository**（自动登录）
>   - 或生成 PAT：GitHub → `Settings` → `Developer settings` → `Personal access tokens` → `Tokens (classic)` → `Generate new token` → 勾 `repo` → 复制 `ghp_...`；push 时用户名填 GitHub 用户名，密码栏**粘贴这串 token**（不是账号密码）

**第 4 步 · 验证**

刷新 GitHub 仓库页面，应看到 `src/`、`public/`、`docs/`、`README.md` 等，并且 `docs/audit/` 下有报告文件。

> 说明：`dist/` 不出现在仓库里是**正常的**（被 `.gitignore` 排除），Codex 云端会自己 `npm run build` 再校验。仓库约 70 MB，其中 `public/assets/video/intro.mp4` 为 24.43 MB，小于 GitHub 单文件 100 MB 上限，可正常推送。  
> 另：`test-artifacts/` 也不进仓库（本地审查截图），但审查结论已写进 `docs/audit/01-游戏本体终审报告.md`，会随仓库提交，Codex 读得到。

## 阶段 4 · 在 Codex 云端创建并发布「环境」（当前版本必需）

> ⚠️ 这一步是 2026 年当前 Codex Cloud 的流程：**必须先有一个已发布（Published）的 Environment，才能开任务**。  
> 而且 Codex **只从远程仓库 checkout**，本地没 push 的改动它完全看不到 —— 所以阶段 3 必须先做完。

1. 打开 ChatGPT 网页版（或桌面 App），用**含 Codex 的账号**登录，确认左侧栏有 **Codex** 入口。
2. 新建任务时选 **Work in → Cloud**，打开 **Select environment → Create environment**（也可走 `Settings → Codex Cloud → Environments → Create environment`）。
3. **Connect GitHub**：按提示跳转 GitHub 授权。授权范围**只勾 `kaizha-game` 这一个仓库**，不要一上来授权全部私有仓库。
4. 回到 Codex，勾选 `kaizha-game`，点 **Get started**。Codex 会自动 clone、识别 `package.json`、安装依赖、试跑工作流；它问什么再补什么。
5. **检查环境里的 Network / Package managers 设置**：需要允许包管理器域名 / 公网访问，否则 `npm install` 和 `npx playwright install chromium`（浏览器测试要用）会下载失败。第一次不要放任何生产级密钥。
6. 检查 setup report / install script，点 **Save** → **Publish**，等到状态显示 **Environment published**。
7. 建议：第一次先用一个「只读小任务」验证 clone / 分支 / diff 正常，再跑正式大任务。

> 常见坑：环境停在 `Unpublished` → 新任务起不来；环境里看不到仓库 → GitHub 授权范围没勾这个仓库。

## 阶段 5 · 粘贴指令并启动任务

1. 在**已发布的环境**里点 **Start a new task**，起始分支选 `main`。
2. 打开 `docs/audit/05-Codex指令-纯文本版.txt`，按 **`Ctrl+A` 全选 → `Ctrl+C` 复制**。
   > 这个文件只有指令正文、没有任何多余说明，最适合直接粘。  
   > 也可以用 `03-Codex云端任务指令.md`，但只复制 `▼ 复制开始` 与 `▲ 复制结束` **之间**的部分，不要把用户清单和两行标记带进去。
3. 粘进任务描述框，发送。
4. 然后可以关掉页面去忙别的 —— Codex 在云端独立沙箱里跑，你的电脑关机也不影响。
5. 它会依次做：复核只读基线 → 建 `codex/final-game-audit` 分支 → 修 P2 / P3 → 重跑完整测试矩阵 → 产出 A–H 报告 → push 分支 → 开 PR。

## 阶段 6 · 检查 PR（确认前不要合并）

任务完成后，Codex 界面会给出分支名与 PR 链接；也可到 GitHub 仓库 → **Pull requests** 查看。逐项核对：

- [ ] PR 是 `codex/final-game-audit` → `main`，`main` 没有被直接改写、没有强推记录
- [ ] `Files changed` 里**没有删除** `public/assets/` 下任何素材
- [ ] A–H 八份报告齐全（终审 / 评分 / 前后对比 / 测试记录 / 修改清单 / 未解决问题 / 分支与 PR / 运行构建说明）
- [ ] 《完整测试记录》里每条命令都有真实的 `EXIT=0` 输出，没有空口写「通过」
- [ ] 新增了「四种结局自然触发」全流程测试，不再只靠注入 state 验证页面可达
- [ ] README 两处不一致已修正（「两款字体」、章节页「39 项」）
- [ ] 《AI 评委四维度评分报告》**没有编造分值与投票比例**（没有真实评委数据就该写「未取得」）
- [ ] 代码里没有 `评委 / AI评 / vote / GPT / Claude / openai / api key` 类操控痕迹

有问题 → 在 PR 里留言，或在同一 Codex 任务里让它继续改（follow-up），改动会进同一分支。  
全部满意 → 才点 **Merge pull request**。

## 卡住了怎么办 · 对照表

| 现象                                       | 原因                            | 处理                                                                 |
| ---------------------------------------- | ----------------------------- | ------------------------------------------------------------------ |
| `git --version` 报「不是内部或外部命令」             | Git 没装 / 终端没重开                | 重装并重开 PowerShell                                                   |
| `git commit` 报 `Author identity unknown` | 没配 `user.name` / `user.email` | 回阶段 2 第 2 步                                                        |
| push 报 `Authentication failed`           | GitHub 不支持账号密码                | 浏览器授权 / PAT / 改用 GitHub Desktop                                    |
| push 报 `remote origin already exists`    | 之前加过                          | `git remote set-url origin <新地址>`                                  |
| push 报「远程仓库有 README 冲突」                  | 建仓时勾了初始化文件                    | 建空仓库，或 `git pull --rebase origin main` 后再推                         |
| GitHub 页面看不到 `dist/`                     | 被 `.gitignore` 排除             | 正常，Codex 会自己 build                                                 |
| Codex 里找不到 `kaizha-game`                 | GitHub 授权范围没选它                | 回授权页把该仓库勾上                                                         |
| 起不了新任务                                   | Environment 未 Publish         | 回环境页 Publish，等 `Environment published`                             |
| `npm install` / Chromium 下载失败            | 环境没开公网                        | 环境 Network 里开 `Package manager domains` / `Public internet access` |
| 测试脚本报找不到 `msedge.exe`                    | 路径是 Windows 硬编码               | 指令里已要求 Codex 改成环境变量 + Playwright Chromium 回落                       |
| Codex 说看不到本地改动                           | 它只拉远程仓库                       | 先 `git push`，再开任务                                                  |

基线提交 `092c027` 用的是局部占位身份 `kaizha <kaizha@localhost>`。改成你的真实身份：

```powershell
$g = "D:\git和node.js lts\Git\cmd\git.exe"
```
